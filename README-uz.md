# Клип — Replicate AI видео интеграция

## Керак бўлади
- Node.js 20 ёки ундан янги версия
- Replicate аккаунти ва API токени
- Replicate ҳисобида тўлов усули/баланс

## Локалда ишга тушириш
1. Бу архивни очинг.
2. Терминалда лойиҳа папкасига киринг.
3. `npm install` буйруғини ишлатинг.
4. `.env.example` файлини `.env` деб нусхаланг.
5. `.env` ичида `REPLICATE_API_TOKEN` қийматига Replicate токенингизни ёзинг.
6. `npm start` буйруғини ишга туширинг.
7. Браузерда `http://localhost:3000` манзилини очинг.

**Токенни HTML/JavaScript ичига ёзманг ва ҳеч кимга юборманг.** `.env` файлини Git ёки оммавий хостингга юкламанг.

## Модель ва харажат
Дастлабки конфигурация `pixverse/pixverse-v6` моделидан фойдаланади:
- 360p, аудиосиз: Replicate модел саҳифасида кўрсатилган нарх $0.05/сония.
- 5 сония: тахминан $0.25
- 10 сония: тахминан $0.50
- 15 сония: тахминан $0.75

Бу тахминий ҳисоб; модел нархи ўзгариши мумкин. Биринчи синовдан олдин расмий саҳифадаги нархни текширинг. Хатолик билан такрорий сўровлар ҳам харажат келтириши мумкин.

## Муҳим чекловлар
- Браузердаги “5 та демо уриниш” фақат интерфейс ҳисоблагичи; ҳақиқий тўловни чекламайди.
- Ушбу версия синов учун: аккаунтлар, ҳақиқий квота, доимий видео тарихи ва тўлов қабул қилиш тизими йўқ.
- Сервер қайта ишга тушса, хотирада сақланган prediction ID рўйхати йўқолади.
- Replicate натижа URL'лари вақтинчалик бўлиши мумкин. Маҳсулотга чиқишда видеоларни доимий файл омборига сақлашни қўшинг.
- Оммавий интернетга чиқаришдан олдин фойдаланувчи аутентификацияси, IP/аккаунт квотаси, харажат лимити, логлаш ва HTTPS қўшинг.

## Хостинг
Аввал локалда синаб кўринг. Кейин Node.js қўллайдиган хостингга deploy қилинг ва `REPLICATE_API_TOKEN` ни хостингнинг Environment Variables қисмида сақланг. Токенни frontend'га киритманг.
